All step to deploy

  1. step1:prepare files to upload (example:thispage =]]])
  2. step2: Login to Github and create NEW RESPOSITORY
  3. step3: In vscode, open terminal with git bash, then use git status to check git status
  4. step4:If it showing "not a git repository" use command git init to create new one
  5. step5:"use git add ." or "git add (file name) or (folder name) to add each file and folder
  6. step6: git commit -m
  7. step7: git branch -M main
